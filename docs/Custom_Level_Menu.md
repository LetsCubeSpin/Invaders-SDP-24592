# KAN-11: JSON 커스텀 레벨 메뉴

`Play → Custom Level`에서 JSON 레벨을 여러 개 가져와 목록에서 선택해 플레이하거나 내보낸다. 모드 선택은 방향키/W/S와 Space, 커스텀 메뉴와 목록은 방향키/W/S와 Space/Enter로 조작한다. Esc/우클릭은 뒤로 간다. 커스텀 레벨은 1인 플레이이며 인원 선택 화면을 거치지 않는다.

## 파일명과 목록 규칙

- Import에서 여러 JSON을 동시에 선택할 수 있다. 가져온 레벨은 게임을 켜 둔 동안 목록에 보관한다. 모드 메뉴에 나갔다 돌아와도 유지되지만 게임 종료 후에는 자동 복원하지 않는다.
- 파일 작업에는 **가져온 파일의 원래 이름과 확장자**를 사용한다. 대소문자·공백·한글도 유지한다. 커스텀 메인 화면은 `Imported Levels: N`으로 목록 개수만 표시한다. 개별 파일명은 Play/Export 선택 목록에서만 표시한다. Play/Export 목록에는 JSON 내부 `name` 대신 원래 파일명에서 마지막 `.json` 확장자만 숨긴 이름을 표시한다(`.JSON`도 동일). 실제 Import/Export 파일명은 바꾸지 않는다.
- 같은 원본 경로를 다시 Import하면 기존 항목을 갱신한다. 갱신 실패 시 기존 항목은 유지한다. 경로는 절대 경로와 정규화한 경로 기준이며 심볼릭 링크 별칭을 합치지는 않는다.
- 서로 다른 폴더의 동명 파일은 각각 보관한다. 목록의 순번과 하단 원본 폴더 경로로 구분한다.
- Play/Export를 누르면 같은 레벨 목록이 열리고 거기서 대상을 선택한다. 한 화면에 7개씩 표시하며 방향키로 다음 항목을 이동하면 다음 페이지를 보여 준다. 위/아래 끝에서는 반대 끝으로 순환한다. Esc는 실행·파일 쓰기 없이 취소한다.
- 파일 이름과 폴더는 시스템 글꼴로 표시해 Unicode 이름을 지원한다. 화면 좌우에 24픽셀을 남기고 **실제 글꼴 폭**을 기준으로 맞춘다. 긴 이름은 가운데를 `...`로 줄여 확장자를 숨긴 이름의 앞부분과 끝부분을 남긴다. 줄바꿈 등 제어 문자는 화면에서만 공백으로 표시한다. 원본 이름과 실제 파일은 바꾸지 않는다.
- Export는 **Import 시점의 레벨 데이터 스냅샷을 기존 JsonLevelWriter로 다시 직렬화**한다. 원본 파일의 바이트 복사가 아니므로 들여쓰기·키 순서가 달라질 수 있다. Import 후 원본 파일을 수정해도 재Import 전까지 반영되지 않는다.
- Export는 **대상 폴더만 선택**하며 `선택한 폴더 / 원래 파일명`에 저장한다. 별도 이름 입력이나 자동 번호 추가는 하지 않는다. 같은 이름의 파일이 있으면 덮어쓰기 확인을 거친다. 다른 폴더의 동명 레벨을 같은 폴더로 Export할 때도 이 확인이 필요하다.

## 직접 확인할 흐름

1. `sh ./gradlew run` 또는 IntelliJ의 `Invaders - Run`을 실행한다. JDK 설정은 [빌드 안내](BUILDING.md)를 따른다.
2. `Play → Custom Level`에 들어간다. 처음에는 `Imported Levels: 0`가 표시되고 Play/Export는 회색이며 실행되지 않는다. 방향키와 W/S는 이 비활성 항목을 건너뛰고 Import와 Back 사이에서 이동한다.
3. `Import JSON`에서 `examples/levels/campaign-stage-01.json`과 다른 JSON을 함께 선택한다. macOS 파일 선택 창에서는 Command를 눌러 여러 파일을 고른다.
4. `Play Level`에서 목록의 레벨을 선택해 실행한다. 종료 후 점수와 남은 생명을 확인하고 커스텀 메뉴로 돌아온다. 공식 하이스코어·캠페인 해금·기록에는 반영하지 않는다.
5. `Export JSON`에서 목록의 레벨을 선택하고 저장할 폴더를 고른다. 원래 파일명으로 저장됐는지 확인한다. 내보낸 파일을 다시 가져와 실행할 수도 있다.
6. 선택 창과 목록 취소, 잘못된 JSON, 덮어쓰기 No를 확인한다. 기존 목록·정의와 기존 저장 파일이 유지되어야 한다. 여러 Import 중 일부가 잘못돼도 성공한 파일은 남는다.
7. 긴 이름·한글 이름·서로 다른 폴더의 같은 이름·8개 이상의 파일을 확인한다. 원본 파일명을 유지한 채 페이지와 폴더 표시로 선택 가능해야 한다.

기존 예제를 덮어쓰지 않으려면 별도의 폴더에 Export한다. 가져오기 대화상자는 기본적으로 `examples/levels`를 연다. 파일 선택 창에서의 확장자 필터와 별도로 기존 reader가 내용을 검증한다.

## 구현 경계와 검증

- Core의 반환 코드 16으로 진입하고 Back은 모드 선택 코드 14로 돌아간다. 기존 Campaign/Endless의 인원 선택과 Story 진입 코드는 유지한다.
- `CustomLevelMenu`는 원본 경로·파일명과 `CustomLevelSession`을 각 항목에 보관한다. 읽기·검증·원본 내보내기·공식 기록 격리는 기존 API를 사용한다.
- 대화상자·목록 선택·Import 등을 포함한 전체 작업에서 예상된 예외를 처리한다. 오류 알림마저 실패하면 로그를 남기고 커스텀 메뉴만 종료해 Core가 모드 메뉴를 다시 열도록 한다. 그때까지 성공한 Import는 유지한다. 인터럽트 상태라면 추가 대화상자를 띄우거나 재시도하지 않는다.
- 파일 선택과 알림만 Swing EDT에서 처리한다. 메뉴 루프가 끝난 후 게임 컨트롤러 스레드에서 파일 작업과 플레이를 실행한다. 다이얼로그 종료 시 키/마우스 눌림 상태를 해제한다.
- `CustomLevelMenuTest`는 실제 JSON 읽기/쓰기로 복수 Import, 대상별 Play/Export, 동명 파일 구분, 재Import, 실패한 갱신 보존, 취소, 원래 파일명 보존, 덮어쓰기 승인/거부, 빈 목록 및 쓰기 실패를 확인한다.
- `FileNameDisplayTest`는 실제 글꼴 폭·표시 확장자 생략·Unicode 코드 포인트·작은 폭·제어 문자 처리를 확인한다.
- `GameModeScreenTest`는 Custom 진입 코드와 기존 모드 반환 코드·인원 선택 개수를 확인한다.

헤드리스 자동 테스트는 실제 macOS 파일 선택 창의 조작이나 화면 전체 플레이를 검증하지 않으므로 위 수동 흐름을 함께 확인한다. 레벨 편집기·2인 커스텀 플레이·타임 어택은 이번 작업 범위에 포함하지 않는다.

- `CustomLevelScreenTest`는 실제 키 이벤트와 화면 update로 빈 목록에서 비활성 항목 건너뛰기, 양방향 순환, W/S, Space 확정, 레벨이 있을 때 전체 항목 순회를 확인한다.
